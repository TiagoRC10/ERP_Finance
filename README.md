# bpoHUB Finance OS

ERP financeiro da **bpoHUB Serviços Contábeis**.

Refatoração do sistema que estava no Lovable (`pocket-joy-dashboard`), agora no Grok Build.

## O que tem hoje

- Dashboard com KPIs (entradas, saídas, fluxo de caixa)
- Contas a pagar e a receber (recorrência, provisão, ações em lote)
- Conciliação OFX com regras automáticas
- Clientes, fornecedores e categorias
- Extrato, relatórios e DRE
- Open Finance (estrutura)
- WhatsApp IA (estrutura)

## Como rodar (para quem programa)

```bash
npm install
npm run dev
```

Abre em `http://localhost:8080`.
